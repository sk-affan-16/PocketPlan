# PocketPlan — Personal Budget Manager

## About
PocketPlan is a personal budget management Android application.

## Features
- Income tracking
- Expense tracking
- Budget management
- Transaction history
- Financial summary

## Tech Stack
- Kotlin
- Android Studio
- XML
- Room Database
- Git & GitHub
